# Migrating to 1.1

Breaking or visible changes since the 1.0 library, in the order you will hit them.

| Area | Change | Action |
|---|---|---|
| `Alert`, `Toast` | variant prop is `tone`; string `style` still works (deprecated) | Rename `style` → `tone` |
| `DataGrid` | renders `role="table"`; requires `label` (or `aria-labelledby`) | Add a label |
| `ComboboxPanel` | no longer autofocuses | Pass `autoFocus` |
| `SelectMenu` | takes a tab stop | Check tab order |
| `CellHistoryPopover` | takes focus on mount | Pass `autoFocus={false}` in galleries |
| `NotificationCenter` | manages focus only when `onClose` is passed | Pass `onClose` |
| `ToolSwitch`, `ColumnItem`, `SearchResultRow`, `SectionSubMenu`, `CompanyInfo` | roles changed (radiogroup, toggle button, option, nav, `h1`) | Re-test queries |
| `GridColumnHeader` | resize handle removed; reorder via `onMove` | Wire `onMove` |
| `Modal` | `role` may be `alertdialog`; `ConfirmationDialog` focuses Cancel when destructive | none |
| **Charts (1.1.0 reliability pass)** | **new ramp: every chart changes colour**; renders via `react-chartjs-2` | Re-check screenshots; `chart.js` and `react-chartjs-2` are installed with the package |
| Form controls | resting border is `Stroke/Control`, hover `Stroke/Strong` | Visual diff only |
| Type | `--font-size-heading-xs` is 12px (was 10px) | Visual diff only |

## Deprecation policy

A deprecated prop or token stays for one minor release with a `@deprecated` note and a
changeset, then is removed in the next minor. Breaking removals need a changeset marked
`major` once the package leaves 1.x.
