# Valuation Modal — structure, states and tokens

One valuation in full, opened from a Workboard row. Built from the workboard Figma file
(`tuFpgEHX8w3BDI40U0FUwV`, section **Assign users form Modal**, `532:16434`). Every colour, space and type
value is a semantic token. The full modal renders in the **Workboard › Valuation Modal** stories (one per
Figma state); this page explains how it is put together.

| Region | Component | Notes |

## The step assignment menu

Each step ends in its people or an assign button. The button opens a picker under the step: chosen people as
removable chips, a filter, Save and a checklist. Escape closes the picker first, then the menu. Reached steps
carry a checked mark and the brand label, and every step says its state in words (R8).

`StepAssignMenu` is not `StepMenu`. `StepMenu` is the menu behind an `ActionPill` caret in a grid row (steps,
tools and actions, no people). Use `StepAssignMenu` where people are put on steps.

## Deal tokens

The Deal card is filled with Teal 500, the workboard file's "Accent". White on it is **2.25:1**, below AA even
for large text, so everything on the card uses Deal/Text. Figma: *Semantic: Color › Deal/\** (published).

In TypeScript: `color.deal.background · text · subtle · subtleText · control`. The contrast gate
(`npm run lint:contrast`) checks text on the fill and on the pill at 4.5:1 and the glyph on the control at 3:1.
A deal is not a status: never use `bg.positive` for it.

## Where Figma and code differ, on purpose

- **12px floor (R10).** Figma's 10px chips and labels are 12px; 16px avatars are Avatar/XS (24px). Long role
  names truncate in narrow cards, with the full text in a tooltip.
- **Links** use `text.link` with a permanent underline (R8), not brand blue.
- **Neutral fills** (Neutral 300–500 in Figma) are `bg.subtle` with a check icon or a control border; there is no
  semantic neutral fill.
- **Icons** are Material Symbols, matched by meaning (known gap 4).
- **Deal card ink** is Deal/Text, not white, until the Figma frames move to the Deal tokens (known gap 14).
