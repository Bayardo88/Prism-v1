# AI Outline — the "AI is working" animation

A 3px ring in the AI gradient (violet → blue → teal → pink), drawn over the item's edge on its own layer,
so the item keeps its own fill and border. While AI works on it, a comet of the gradient orbits the edge
**once every 3 seconds** with a matching glow just outside the edge, following every corner, with no seam. Still, or under reduced motion, the whole
ring shows. The full developer guide is `docs/ai-outline.md`.

<Canvas of={FeedbackPatternsStories.AiOutlines} />

## Use it

| Situation | Code |
| --- | --- |
| A model is working on the item | `<AiOutline>…</AiOutline>` (or `active`) |
| AI-made, nothing running | `<AiOutline active={false}>…</AiOutline>` |
| Outline on your own card / article | `<AiOutline asChild><article>…</article></AiOutline>` |
| The notification bell while AI works | `<Notification working />` |
| A fill or border | the host's own `background` / `border`; the ring never changes them |

Always pair it with words or a `Spinner`: the outline is decorative and never says "working" on its own (R8).

## How it moves

| Value | |
| --- | --- |
| Technique | `conic-gradient(from var(--scalar-ai-outline-angle), …)` on a `::before` layer, masked to its 3px border (border-beam) |
| Comet | 245° → 355° coloured, the rest transparent |
| Animated property | `--scalar-ai-outline-angle`, registered with `@property` as `<angle>`, 0° → 360° |
| Duration · easing | 3s · linear · infinite |
| Glow | the comet on `::after`, blurred 8px at 0.6 and masked to a `space.m` band outside the edge |
| Reduced motion | No comet or orbit: the whole ring shows still |
| Fallback | Without `@property` support the comet renders still |
