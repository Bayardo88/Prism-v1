How this zip works

The archive is a design-system drop, not an app. An agent reads the Cursor rule, the app imports one stylesheet, and every color, size, and type style is supposed to come from the JSON source.

design-tokens.json

DTCG source. Primitives hold raw values. Semantic colors alias those primitives and carry a dark-mode extension. Typography styles compose family, size, weight, and line height.

tokens.css

Generated variables. Import it once. Light values sit on :root. data-theme="dark" overrides the semantic colors. The file also follows the OS dark scheme unless the root is pinned to light.

.cursor/rules/design-system.mdc

Always-on instructions. Components must use semantic tokens, an 8px space scale, the type styles, and the button, input, card, table, badge, and alert recipes.

Naming: JSON color.action.primary.default becomes CSS --color-action-primary-default. A reference {color.brand.600} becomes var(--color-brand-600).
